Project Write-Up

Rationale

Our goal was to make it easy to explore how temperatures across California could change over time under different greenhouse gas emissions scenarios. We chose an interactive geographic heatmap because it allows users to see not only how temperatures change over time, but also how those changes vary across different parts of the state.

We represent annual average temperature using color. Each grid cell is colored according to its temperature, with lighter yellow colors representing lower temperatures and darker orange and red colors representing higher temperatures. This encoding makes spatial temperature differences easy to recognize at a glance. We also included a color legend.

We chose a geographic map rather than a traditional line chart because our main goal was to show the spatial distribution of temperature across California. A line chart would be useful for comparing temperature trends over time, but it would not communicate geographic differences as directly.

We included two main interactive controls: an emissions scenario dropdown and a year slider. The dropdown allows users to switch between the low-emissions SSP1-2.6 and high-emissions SSP5-8.5 scenarios. The slider lets users explore temperatures from the historical period through 2100. When either control changes, the map updates to display the corresponding temperatures. Users can also hover over or tap individual grid cells to see the cell's approximate coordinates and exact annual average temperature.

Development Process

We developed our application using HTML, CSS, JavaScript, and D3.js, with Python used separately for data preparation. We divided the application into multiple files to keep the code organized and make it easier to work on different parts of the project.

HTML was used to establish the structure of the webpage, including the map container, emissions scenario dropdown, year slider, and other interface elements. CSS was used to style the webpage and make the visualization easier to navigate. JavaScript and D3.js were responsible for creating the geographic heatmap, mapping temperature values to colors, and implementing the interactive features. In particular, D3.js allowed us to dynamically update the map as users changed the selected year or emissions scenario.

The data preparation process was implemented separately in Python. We retrieved monthly temperature data from the CMIP6 dataset using the GFDL-ESM4 climate model for the historical period and two future emissions scenarios. We processed the monthly measurements into annual average temperatures, converted the values from Kelvin to Celsius, and accounted for differences in the number of days in each month when calculating the averages.

We also retrieved California's geographic boundary and used it to generate a grid of geographic cells covering the state. Each cell was associated with its temperature values across the available years and scenarios. Finally, we exported the processed data into a JSON file.
